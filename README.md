# Асинхронный сервис автоматизации бронирования и записи (Booking Service API)

Современный, быстрый и безопасный бэкенд-сервис для автоматизации онлайн-записи к мастерам (салоны красоты, автосервисы, частная практика). Написан на асинхронном стек технологий Python с соблюдением лучших практик проектирования веб-приложений (REST API, CRUD, RBAC, Миграции).

## 🚀 Ключевой функционал

*   **Надежная JWT-авторизация (OAuth2):** Хэширование паролей с помощью `bcrypt`, генерация токенов и строгая валидация времени жизни сессий.
*   **Ролевая модель доступа (RBAC):** Разграничение прав для Клиентов (`client`), Мастеров (`master`) и Администраторов (`admin`). Защита эндпоинтов от несанкционированного доступа.
*   **Умная бизнес-логика расписания:**
    *   Автоматический расчёт времени окончания услуги на основе её длительности.
    *   Строгий запрет на создание бронирований на прошедшее время.
    *   Математический алгоритм валидации наложений (блокировка пересекающихся слотов у одного мастера).
*   **Продвинутый менеджмент данных:**
    *   Гибкая фильтрация каталога услуг по query-параметрам (`min_price`, `max_price`).
    *   Постраничная пагинация списков бронирований (`limit`, `offset`) для защиты сервера от перегрузок.
*   **Промышленная конфигурация:** Вынесение секретных ключей и доступов к СУБД в изолированные файлы окружения (`.env`) через `Pydantic Settings`.
*   **Контроль версий БД:** Интеграция с `Alembic` для автоматической генерации и отслеживания асинхронных миграций PostgreSQL.

## 🛠️ Стек технологий

*   **Язык разработки:** Python 3.12+
*   **Фреймворк:** FastAPI (Асинхронный)
*   **ORM:** SQLAlchemy 2.0 (Async)
*   **Драйвер БД:** Asyncpg
*   **База данных:** PostgreSQL
*   **Валидация данных:** Pydantic v2 & Pydantic Settings
*   **Миграции:** Alembic
*   **Безопасность:** PyJWT, Bcrypt, Паттерн Ролей-Депендов

## ⚙️ Инструкция по локальному развертыванию

### 1. Клонирование репозитория и подготовка окружения
```bash
git clone https://github.com
cd booking_service
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
```

### 2. Настройка переменных окружения
Создайте файл `.env` в корне проекта:
```env
SECRET_KEY=SUPER_SECRET_KEY_FOR_BOOKING_SERVICE_123
ALGORITHM=HS256
ACCESS_TOKEN_EXPIRE_MINUTES=30
DATABASE_URL=postgresql+asyncpg://postgres:postgres@localhost:5432/booking_db
```

### 3. База данных и миграции
Убедитесь, что служба PostgreSQL запущена, и примените актуальное состояние миграций:
```bash
sudo service postgresql start
alembic upgrade head
```

### 4. Запуск веб-сервера
```bash
uvicorn app.main:app --host 0.0.0.0 --port 8000 --reload
```
После запуска интерактивная интерактивная документация API (Swagger UI) будет доступна по адресу: `http://localhost:8000/docs`
